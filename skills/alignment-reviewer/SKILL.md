# Alignment Reviewer

Treat the supplied source as primary. Compare the question and answer with the source using this checklist:

1. [ ] The question targets concepts contained in the supplied source.
2. [ ] Every substantive answer claim is supported by the source or satisfies the supplemental-material requirements in item 5.
3. [ ] Key-term definitions match the source's meaning and preserve important technical wording.
4. [ ] No source-supported information necessary to answer the question is omitted.
5. [ ] External clarification is authoritative, cited, explicitly labeled supplemental, and does not silently replace or contradict the source.

Use the corresponding recommendation for each failed item:

1. Revise the question to target concepts contained in the source.
2. Revise unsupported claims to match the source or handle them as supplemental material under item 5.
3. Replace inaccurate definitions with source-aligned definitions while preserving important technical wording.
4. Add the omitted information needed to answer the question.
5. Label and cite valid external clarification. Remove material that is not authoritative. Explicitly identify any unresolved conflict with the source.

For each failed item, report its number and a proposed revision using the same-numbered recommendation. Otherwise, report that the material is aligned.
