# Duplication Reviewer

Review the source map, learning objectives, and completed detailed notes using this checklist:

1. [ ] No two questions test the same concept and relationship.
2. [ ] Definitions and reasoning are not fully repeated across notes unless needed for local understanding.
3. [ ] Within each note, the general principle, learning aid, and source-specific example provide distinct learning value.

Use the corresponding recommendation for each failed item:

1. Keep one question for the duplicated concept and relationship, combining any necessary coverage into it. Revise another question only when it can test a distinct application, mechanism, limitation, or trade-off.
2. Keep the complete definition or reasoning in the most relevant note. Replace repeated versions with a brief reminder or internal reference while preserving local understanding.
3. Give each component a distinct role: the general principle answers and explains, the aid demonstrates or visualizes, and the source-specific example anchors the concept to the source. When the aid explains the concept better, preserve it and shorten the general principle to its essential explanation and qualifications.

Do not flag:

- Shared terminology without repeated definitions.
- Brief prerequisite reminders.
- Repeated qualifications whose omission would mislead.
- Different representations or applications that add learning value.
- The same source material used for different learning functions.

For each failed item, report its number, the affected objectives or components, and a proposed revision using the same-numbered recommendation. Otherwise, report that no unnecessary duplication was found.
